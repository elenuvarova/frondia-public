# Полоса доказательств — референсы (09.10.2026)

Скриншоты — чужие (OpenAI, Mapbox): лежат только локально (в .gitignore), здесь — ссылки на источник.

Поиск: Refero (стили и экраны) и Mobbin (секции сайтов). Запросы — пара снимков «до/после» с подписью-числом,
сравнение спутниковых снимков, редакционная статья с фото-доказательствами, слайдер «до/после».

## Выбор

**Основной — OpenAI, DALL·E 3, секция сравнения** (`openai-dalle3-pair.webp`,
https://mobbin.com/sites/sections/88a31de0-8431-4a5e-a8df-8761600e6676).
Одна строка утверждения по центру сверху; ниже две равные картинки бок о бок с узким зазором; под каждой — короткая
подпись мелким кеглем, что это и откуда. Светлое полотно, без карточек и теней. Это редакционный «рисунок с подписью» —
та же логика, что у research-статей anthropic.com, principal layout лендинга.

**Заимствуем узко:**
- **OpenAI, DALL·E 2, два числа** (`openai-dalle2-stats.webp`,
  https://mobbin.com/sites/sections/2740b6f4-c138-41e3-bcb1-a73038df24c9): два крупных числа рядом, под каждым
  подпись в две строки. Роль — только пара «официальная карта / аэрофото» под снимками, не украшение.
- **Mapbox, статья о снимках 30 см** (`mapbox-imagery-article.jpg`,
  https://refero.design/pages/5129ea38-2dc7-44d2-85e3-94dd9ef4cdf6): подпись под парой называет, где «до», где «после»,
  и источник снимков отдельной фразой («Previous imagery on the left, updated imagery on the right. Imagery from …»).
  Роль — строка источника и лицензии.

## Reference lock

- **Сохранить:** утверждение одной строкой над парой; две картинки равного размера, общий нижний край; подпись под
  каждой; числа под парой; источник — отдельной строкой мелким кеглем.
- **Роли:** числа — данные из `facts.editions` и `facts.be_vegetation`, не вписанные руками; цветом не красить: это не
  эффект против порога, а сравнение двух источников (чирок и красный на сайте значат только «сверх порога»).
- **Медиа:** реальные ортофото с кремовым контуром сектора (#F2EADE, 4 px), квадрат или 4 : 3, одна рамка на пару;
  подписи «summer 2018 / summer 2021».
- **Отвергнуто:** числа поверх фото (Zipline, Paraform, T1 Energy) — текст на аэрофото прячет доказательство;
  тёмное полотно (Sana, Mapbox) — лендинг кремовый; карточки статистики с иконками (Biograph) — маркетинг, не
  доказательство; слайдер с ручкой — уже есть в аудитах, второй такой же на лендинге повторит приём.

## Decision ledger

| Решение | Источник | Почему |
|---|---|---|
| Утверждение над парой, по центру | OpenAI DALL·E 3 | один тезис на рисунок, как в research-статье |
| Две равные картинки бок о бок | OpenAI DALL·E 3, Mapbox | сравнение глазом без взаимодействия |
| Подпись под каждой: год и что это | OpenAI DALL·E 3 | снимок без подписи на сайте-доказательстве не ставится |
| Пара чисел под снимками | OpenAI DALL·E 2 | разница 8 → 62 против 41 → 47 читается за секунду |
| Строка источника и лицензии | Mapbox | Vlaamse Open Data и CC BY требуют подписи |
| Без цвета у чисел | правило сайта «цвет = измерение» | это не эффект сверх порога |
| На телефоне — пара столбиком, числа под каждой | правило сайта (390 px, без бокового скролла) | две картинки рядом на 390 px нечитаемы |
